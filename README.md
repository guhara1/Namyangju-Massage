# 간다GO — 남양주 출장마사지·홈타이 지역 SEO 사이트

경기도 남양주시에서 방문형 마사지(출장마사지)·홈타이를 찾는 사용자가
본인 위치에 맞는 지역 정보를 쉽게 확인할 수 있도록 만든 정적 지역 SEO 사이트입니다.
남양주시는 행정구가 없으므로 **메인 → 읍·면·대표 행정동 → 지하철역·철도역** 구조로 구성합니다.

- **상호:** 간다GO
- **예약전화:** 0508-202-4719
- **핵심 키워드:** 출장마사지 / **보조:** 홈타이
- **지역 키워드:** 남양주 출장마사지, 남양주시 출장마사지, 남양주 홈타이

## 구조 (총 38페이지)

```
메인 1
읍·면·대표 행정동 15   (와부읍·진접읍·화도읍·진건읍·오남읍·퇴계원읍·별내면·
                        수동면·조안면·호평동·평내동·금곡동·양정동·다산동·별내동)
지하철역·철도역 17      (다산역·별내역·별내별가람역·오남역·진접역·도농역·양정역·
                        덕소역·도심역·팔당역·운길산역·퇴계원역·사릉역·금곡역·
                        평내호평역·천마산역·마석역)
안내 페이지 5          (예약안내·이용 전 확인사항·홈타이 이용 가이드·
                        개인정보처리방침·고객센터)
```

번호 행정동(다산1·2동)은 개별 페이지를 만들지 않고 대표 동(다산동)으로 통합합니다.
예정역(왕숙역·풍양역)은 단독 색인 페이지를 만들지 않으며, 별내선 연장 이슈는
별내동·별내역 본문에서 보조 설명으로만 다룹니다. 별내역은 경춘선·8호선 환승역이지만
노선별로 나누지 않고 1개 페이지로 처리합니다.

## URL 규칙

| 구분 | 경로 |
|------|------|
| 메인 | `/` |
| 읍·면·동 | `/namyangju/<slug>-chuljangmassage/` |
| 역세권 | `/namyangju/<station>-station-chuljangmassage/` |

> 메인페이지는 배포 도메인 루트(`/`)에 위치합니다. 워드프레스 슬러그
> `/namyangju-chuljangmassage/`로 운영하려면 해당 경로로 리다이렉트하세요.

## 빌드

```bash
python3 build.py
```

`content/` 패키지의 페이지 정의를 읽어 각 경로에 `index.html`을 생성하고
`sitemap.xml`, `robots.txt`, `.nojekyll`을 갱신합니다.

- 본문 텍스트 2,000자 미만 페이지는 자동으로 `noindex` 처리됩니다.
- 모든 페이지에 `WebPage`·`BreadcrumbList` 구조화 데이터가 자동 삽입되고,
  메인에는 `Organization`·`FAQPage`가 추가됩니다.
- 오프라인 매장 주소가 없으므로 `LocalBusiness` 스키마는 사용하지 않습니다.

## 배포 전 설정

- `content/site.py`의 `BASE_URL`을 실제 도메인으로 변경한 뒤 `python3 build.py` 재실행.
